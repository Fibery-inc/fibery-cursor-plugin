# Use Fibery MCP

Skills and tool recipes are provided by the Fibery remote MCP server after OAuth.

## When to use

- Browse or change Fibery workspace schema (spaces, databases, fields)
- Query or update entities
- Read Fibery docs / user guide in context of the workspace

## Do

1. Confirm the Fibery connector is connected (OAuth to the user's workspace).
2. Call Fibery MCP tools for schema and data — do not invent entity types or field names.
3. Prefer server-provided skills when the host surfaces them.

## Do not

- Invent Fibery API payloads or workspace structure
- Paste API tokens into chat
